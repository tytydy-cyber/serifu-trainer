# セリフトレーナー

小劇場俳優のための台詞覚え支援ツール。台本（PDF / Word / テキスト）を取り込むと、役名とセリフを自動で読み取り、出番ごとにまとめてマスク練習・音声稽古ができます。

**使う → [https://tytydy-cyber.github.io/serifu-trainer/](https://tytydy-cyber.github.io/serifu-trainer/)**

ログイン・アカウント登録は不要です。上のリンクをスマホやPCのブラウザで開くだけで、誰でもすぐに使えます。

## できること

- 台本の取り込み（PDF・Word・テキスト貼り付け）と、役名・セリフの自動判定
- 自分の役を選ぶと、出番（自分のセリフが続くまとまり）ごとに一覧表示
- マスク練習：自分のセリフを伏せて、段階的にヒントを出しながら思い出す
- 通し表示：出番の全文を、自分のセリフだけ伏せた状態で読み返せる
- 音声稽古：相手のセリフを端末が読み上げ、自分の番で止まって声に出す練習ができる
- 場面ごとに「動き（立ち位置・移動）」「小道具」をメモできる
- 台本が改訂されたら、変更元を指定して取り込み直すだけで、変わった箇所だけを洗い出して練習できる

## 使い方の流れ

### 1. 台本を取り込む

ホーム画面の「＋ 台本を取り込む」から、4つのステップで進みます。

1. **台本を読み込む** — PDF・Word（.docx）・テキストファイルを選ぶか、本文を直接貼り付けます。タイトルや「稿」（第◯稿など）、本番日をあわせて入力できます。
2. **役名を確認** — 自動で読み取った役名の候補が並びます。役でないものはチェックを外し、「男」と「男Ａ」のような表記ゆれは同じ表示名にそろえると1つの役にまとまります。
3. **自分の役** — 自分が演じる役にチェックを入れます。一人二役の場合は両方にチェックしてください。
4. **仕上げ** — 読み取り結果を確認します。うまく判定できなかった行（「要確認」）だけを絞り込んで、その場で種類や役を直せます。おかしな箇所がなければそのまま保存して構いません。

うまく読み取れないときは、下の「よくある質問」も参考にしてください。

### 2. 出番を選んで練習する

台本を保存すると、自分のセリフが続くまとまりごとに「出番」として一覧表示されます。「今日やるのは出番3だけ」のように、稽古する範囲を選んで開いてください。それぞれの出番から、マスク練習と音声稽古のどちらかを選べます。

### 3. マスク練習

自分のセリフを伏せ字にして、タップするたびに「文字数だけ分かる」→「頭の数文字」→「最初の一文」→「全文」の順にヒントが開いていきます。ヒントを見た（または全文を開いた）状態でもう一度タップすると、「言えた」「怪しい」「出なかった」のいずれかで記録されます。ヒントを多く使いすぎた場合は「言えた」を選べないようになっています。

### 4. 音声稽古

「稽古を始める」を押すと、相手のセリフを端末が読み上げます。自分の番になると読み上げは止まり、実際に声に出して言ってみる時間になります。画面をタップするか、一定時間経つと答えのセリフが表示されるので、そこで判定します。役ごとに読み上げの声を変えられるので、掛け合いの相手が誰かも聞き分けられます。

### 5. 台本が改訂されたら

稽古期間中に台本が変わるのはよくあることです。新しい稿を取り込むときの「台本を読み込む」画面で、「改訂元の台本」に元の台本を選んでください。保存すると、

- セリフが変わっていない箇所は、それまでの練習記録（言えた／怪しい／出なかった）をそのまま引き継ぎます
- 言い回しが変わった箇所は「怪しい」として登録し直され、忘れずに確認できます
- 新しく追加されたセリフは未練習として扱われます

台本詳細の「出番」タブ上部に、何箇所変わったか・どの出番に影響があるかが表示され、変更点だけをその場で見比べることもできます。

## プライバシー

台本データは一切サーバーに送信されません。取り込んだ内容はすべて、その端末のブラウザ内（IndexedDB）だけに保存されます。他の人と共有したい場合は、ホーム画面の「書き出し」からバックアップファイルを書き出し、相手が「バックアップから復元」で読み込んでください。

## インストール（任意）

スマホでホーム画面に追加すると、アプリのように起動できます（オフラインでも動作）。

- **Android (Chrome)**: サイトを開き、メニュー（︙）→「ホーム画面に追加」
- **iOS (Safari)**: サイトを開き、共有ボタン →「ホーム画面に追加」

## よくある質問

**PDFの文字がうまく読み取れない**
画像として保存されたPDF（スキャンしたものなど）は文字を読み取れません。また、まれに一部の文字だけが別の文字として読み取られることがあります（埋め込みフォントの問題）。元がGoogleドキュメントやWordの場合は、「.docx」または「.txt」で書き出してから取り込み直すと解決することが多いです。それでもうまくいかない場合は、本文をコピーして「文字を貼り付け」から取り込んでください。

**Googleドキュメントの台本を取り込みたい**
ドキュメントを開き、「ファイル → ダウンロード → Word (.docx)」で保存してから、そのファイルを選んでください。

**音声稽古で読み上げが始まらない・声が出ない**
端末に日本語の読み上げ音声が入っていない可能性があります。端末の設定から日本語の音声合成データを追加すると使えるようになります。それまではマスク練習をご利用ください。

**iPhoneで音声稽古中に画面が消えると読み上げが止まる**
Webアプリ（PWA）の仕様上の制約で、画面がロックされたりバックグラウンドに回ったりすると読み上げは止まります。稽古中は画面を点けたままにしてください。

**機種変更したい・他の端末やスマホとPCでデータを共有したい**
台本データは端末の中だけに保存されており、自動では同期されません。ホーム画面の「書き出し」でバックアップファイル（JSON）を保存し、別の端末で「バックアップから復元」から読み込んでください。

**「要確認」の行が多い**
役のセリフともト書きとも自動判定できなかった行です。多くはタイトルや登場人物表など、練習には関係のない部分です。気になる場合だけ「仕上げ」ステップで種類や役を直してください。

## トラブルシューティング

- **台本データが消えてしまった** — 台本はブラウザ内（IndexedDB）に保存されているため、ブラウザの「閲覧データを削除」を行うと台本も一緒に消えます。定期的にホーム画面の「書き出し」でバックアップを取っておくことをおすすめします。
- **役名の候補が正しく拾えない** — 台本の書き方（役名の後ろに「：」や「「」」などの区切りがあるか）によって精度が変わります。候補が少ない・多すぎる場合も、「仕上げ」ステップで手動で直せます。

## 開発

ビルドツール不要の素の HTML / CSS / JavaScript（ESモジュール）です。`index.html` を静的にホスティングするだけで動作します。

```
python3 -m http.server 8000
```
